// featured project

An agentic performance-testing pipeline.

Every night, AI agents load-test a real app, self-heal their own script, flag regressions against past runs and trace errors to the exact line of code. Token-smart, serverless, and pluggable into your own app and LLM.

01

Pull latest code

Fetch the newest commit. No change, no run.

02

Sanity test

One user, 20 s: is the script still valid?

03

Self-heal if needed Agent

A broken script is repaired by an agent.

04

Run the load test

250 users, 1 min; CPU, memory, network tracked.

05

Analyze results

Response times, errors and spikes vs earlier runs.

06

Inspect the logs

Stack traces and GC pauses vs the spikes.

07

Correlate with code Agent

Trace each problem to a file, line and cause.

08

Final report

Locust, infra and fix report on GitHub Pages.

Agent steps use an LLM, only when needed. The rest is plain code, and unchanged code is never re-tested.
